# 🎡 Educational Roulette Simulator

একটি সম্পূর্ণ শিক্ষামূলক রুলেট সিমুলেটর অ্যাপ্লিকেশন যা সম্ভাবনা তত্ত্ব এবং গেমিং মেকানিক্স বোঝার জন্য ডিজাইন করা হয়েছে। **এটি বাস্তব অর্থের সাথে কোনো সম্পর্ক নেই।**

## ✨ বৈশিষ্ট্য

### 🎰 গেম মেকানিক্স
- **সম্পূর্ণ রুলেট হুইল**: 0-36 সংখ্যা সহ সঠিক রঙের নিয়ম
- **একাধিক বেটিং অপশন**:
  - সিঙ্গেল নাম্বার (36:1 পেআউট)
  - রঙ - লাল/কালো/সবুজ (1:1 পেআউট)
  - জোড়/বিজোড় (1:1 পেআউট)
  - রেঞ্জ - 1-12, 13-24, 25-36 (2:1 পেআউট)

### 📊 পরিসংখ্যান ট্র্যাকিং
- মোট স্পিন সংখ্যা
- ভার্চুয়াল ব্যালেন্স (1000 ক্রেডিট দিয়ে শুরু)
- জয়ের হার শতাংশ
- মোট জয়ের সংখ্যা

### 🎮 ইউজার ইন্টারফেস
- আকর্ষণীয় এবং প্রতিক্রিয়াশীল ডিজাইন
- রিয়েল-টাইম অ্যানিমেশন
- মোবাইল-বান্ধব লেআউট
- সহজ নেভিগেশন

### 📚 শিক্ষামূলক মূল্য
- সম্ভাবনা গণনা বোঝা
- ঝুঁকি ব্যবস্থাপনা শেখা
- প্রত্যাশিত মূল্য গণনা
- কেন ক্যাসিনোর সর্বদা সুবিধা রয়েছে তা বোঝা

## 🎯 রুলেট নিয়ম

### রঙের নিয়ম
- **লাল**: 1, 3, 5, 7, 9, 12, 14, 16, 18, 19, 21, 23, 25, 27, 30, 32, 34, 36
- **কালো**: অন্যান্য সব সংখ্যা (0 ছাড়া)
- **সবুজ**: 0

### পেআউট টেবিল

| বেট ধরন | পেআউট | সম্ভাবনা |
|---------|--------|----------|
| সিঙ্গেল নাম্বার | 36:1 | 1/37 (2.7%) |
| রঙ (লাল/কালো) | 1:1 | 18/37 (48.6%) |
| জোড়/বিজোড় | 1:1 | 18/37 (48.6%) |
| রেঞ্জ | 2:1 | 12/37 (32.4%) |

## 🚀 কিভাবে ব্যবহার করবেন

### 1. অ্যাপ খুলুন
```bash
index.html ফাইল ব্রাউজারে খুলুন
```

### 2. বেটিং স্টেপ
1. একটি বেটিং টাইপ নির্বাচন করুন (সংখ্যা, রঙ, জোড়/বিজোড়, রেঞ্জ)
2. আপনার পছন্দের বিকল্প নির্বাচন করুন
3. বেট পরিমাণ নির্ধারণ করুন (দ্রুত বেট বা ম্যানুয়াল ইনপুট)
4. "স্পিন দ্য হুইল" বোতাম ক্লিক করুন

### 3. ফলাফল দেখুন
- হুইল ঘোরানো হবে
- ফলাফল প্রদর্শিত হবে
- পরিসংখ্যান আপডেট হবে

### 4. খেলা পুনরায় শুরু করুন
- "রিসেট গেম" বোতাম দিয়ে নতুন করে শুরু করুন
- সমস্ত পরিসংখ্যান এবং ব্যালেন্স রিসেট হবে

## 💡 শিক্ষামূলক অন্তর্দৃষ্টি

### প্রত্যাশিত মূল্য
রুলেটে প্রতিটি বেটের জন্য:
- **সিঙ্গেল নাম্বার**: E(V) = (36/37) × (-1) + (1/37) × 36 = -0.027 (ক্যাসিনোর সুবিধা 2.7%)
- **রঙ/জোড়-বিজোড়**: E(V) = (18/37) × 2 - 1 ≈ -0.027

### গুরুত্বপূর্ণ পাঠ
1. **ক্যাসিনো সর্বদা জয়ী হয়** - প্রতিটি বেটে নেতিবাচক প্রত্যাশিত মূল্য
2. **দীর্ঘমেয়াদী পরিসংখ্যান গুরুত্বপূর্ণ** - আরও বেশি স্পিন, আরও স্পষ্ট ফলাফল
3. **ঝুঁকি ব্যবস্থাপনা জরুরী** - ছোট বেট দিয়ে শুরু করুন
4. **সম্ভাবনা অপরিবর্তনীয়** - প্রতিটি স্পিন স্বাধীন
